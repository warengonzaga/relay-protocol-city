## Attribution and live-data boundaries

The configured local API key is server-side. Five Scout-provided sample IDs were fetched from `/requests/v3` with authenticated data requested. All five were successful and normalize correctly from actual input/output currency chain fields; their referrer fields were omitted under the available key. They therefore normalize to **Unknown app**. Named-building routing requires a returned matching referrer and never infers one from ranking, amount, chain, or wallet. No raw sample IDs, volumes, logs, or credentials are published.

The skyline ranking covers named external integrators across available Ethereum-involved history from January 1, 2025 to September 30, 2026. It is not proof of pre-2025 lifetime coverage and is independent of the current sample. INTEGRATORS.md records methodology and alias provenance.

Both live and demo scenes include only requests with both endpoints Ethereum/Base. Other chains are excluded without remapping. Fomo's representative live sample had an unsupported destination and is correctly excluded. District geometry stays hand-authored and fixed; Base remains a connection point awaiting its own design pass.

The scene caps at 40 travelers and 150 queued live requests, with up to 150 unresolved trains tracked separately until successful. Exact-ID refreshes rotate through unresolved IDs in batches of 12. Missing updates never invent completion. Completed requests replay; all traveler positions are API-stage metaphors, not exact locations of funds. Simulations are labeled explicitly. Global daily totals and network-wide pending visibility are not established.

## Delivery boundary

GitHub Pages publishes only the static `dist/` artifact. The public site remains in labeled demo mode until a public API URL is configured. No Railway deployment or account mutation is part of this revision. Successful Pages workflow completion and public artifact readback are required before claiming publication.

The earlier split-hosting checks remain applicable: the separate non-root API container serves health/activity, rejects frontend and `.env` paths, and applies configured browser-origin rules. That container was not redeployed to Railway here.
